# 산업연관표 분석 웹앱

과제물1: 투입산출표(산업연관표)로 **수요 증가의 파급효과를 계산**하고 **핵심산업을 찾는** 웹앱입니다.
서버 없이 브라우저 안에서 모든 계산을 실행합니다.

**바로 사용하기:** https://rlaxongs1234-boop.github.io/Industrial-Organization/

## 주요 기능

| 메뉴 | 하는 일 |
|---|---|
| 원자료 탐색 | 시트와 행을 고르면 그 행이 각 열(산업)과 어떻게 연결되는지 값을 보여 줍니다. 행 이름과 열 이름·코드로 검색할 수 있습니다. |
| 시뮬레이션 | 산업별 최종수요 증가액을 입력하면 생산유발액, 수입유발액, 부가가치유발액, 생산유발승수, 부가가치유발률을 계산합니다. 여러 산업을 한 번에 입력하면 합산합니다. 결과 카드를 누르면 계산식과 과정을 볼 수 있고, 전체 산업 결과는 CSV로 내려받을 수 있습니다. |
| 연쇄효과 분석 | 영향력계수와 감응도계수로 산업을 네 유형으로 나눠 핵심산업을 찾습니다. 유형별 필터, 검색, 정렬, CSV 다운로드를 지원합니다. |
| 파급 단계 예시 | 화면 오른쪽에서 산업을 고르면, 그 산업의 수요가 1,000백만원 늘 때 생산이 1차, 2차 파급으로 이어지는 모습을 막대로 보여 줍니다. |

## 사용 방법

1. 오른쪽 **분석할 분류**에서 대분류, 중분류, 소분류, 기본부문 중 하나를 누릅니다. 데이터를 불러오고 계수를 검증하면 "준비 완료"가 표시됩니다.
2. 왼쪽 메뉴에서 원자료 탐색, 시뮬레이션, 연쇄효과 분석 중 하나를 고릅니다.
3. 시뮬레이션은 산업과 증가액(백만원)을 입력해 **시나리오에 추가**한 뒤 **파급효과 계산**을 누릅니다.

분류를 바꾸면 입력한 시나리오는 초기화됩니다. 1,000백만원은 10억원입니다.

## 분석 방법

계산은 투입산출표의 계수 시트를 그대로 읽어 행렬 곱으로 수행합니다.

```
생산유발액      X = L × Y        L: 생산유발계수 행렬 (I − Ad)^-1
수입유발액      M = M̂ × Y        M̂: 수입유발계수 행렬
부가가치유발액  V = V̂ × Y        V̂: 부가가치유발계수 행렬
                                  Y: 산업별 최종수요 증가액 벡터
생산유발승수 = 생산유발액 합계 ÷ 수요 증가액 합계
```

**연쇄효과**는 생산유발계수 행렬 L의 합계로 구합니다. 두 계수 모두 단위 없는 비율입니다.

```
영향력계수 (후방연쇄) = 열합계 ÷ 열합계의 평균
감응도계수 (전방연쇄) = 행합계 ÷ 행합계의 평균
```

| 유형 | 조건 |
|---|---|
| 핵심산업 | 영향력 ≥ 1 그리고 감응도 ≥ 1 |
| 후방연쇄 선도 | 영향력 ≥ 1, 감응도 < 1 |
| 전방연쇄 선도 | 영향력 < 1, 감응도 ≥ 1 |
| 낮은 연쇄 | 둘 다 < 1 |

**파급 단계 예시**는 국산투입계수 행렬 A로 `Y, AY, A²Y, …`를 차례로 더한 값이며, 7차 이후는 합계에 포함됩니다. 모두 더하면 생산유발액(L × Y)과 같습니다. 이 그림은 2023년 대분류(33개 부문) 값으로 고정돼 있어 분류를 바꿔도 달라지지 않습니다.

## 데이터

원자료는 투입산출표(2023연장), 생산자가격 기준 엑셀 파일이며 `data/` 폴더에 있습니다. 금액 단위는 **백만원**입니다.

| 분류 | 산업 수 | 파일 크기 |
|---|---|---|
| 대분류 | 33개 | 0.6MB |
| 중분류 | 83개 | 1.2MB |
| 소분류 | 165개 | 3.1MB |
| 기본부문 | 380개 | 12.3MB |

각 파일은 12개 시트(총거래표, 수입거래표, 국산거래표, 투입계수, 유발계수, 최종수요 항목별 유발액 등)를 포함합니다.

## 계산 검증

데이터를 불러올 때마다 아래 세 관계식의 오차가 허용값 1e-8 미만인지 확인하고, 통과하지 못하면 분석을 시작하지 않습니다. 결과는 화면 오른쪽 **데이터 상태 → 계수 검증 결과**에서 볼 수 있습니다.

- 생산: (I − Ad) × L = I
- 수입: Am × L = M̂
- 부가가치: 부가가치계수 × L = V̂

`validation-report.json`에는 기본부문(380개)에서 확인한 결과가 기록돼 있습니다. 최대 절대 잔차는 모두 1e-14 이하이고, 벼 부문의 국내 수요 1,000백만원 증가 테스트에서 생산유발액 1,362.02, 수입유발액 89.28, 부가가치유발액 910.72(생산유발승수 1.362)가 나왔습니다. 이 기록은 Python 계산 모듈에 대한 검증입니다.

## 기술 구성

- HTML, CSS, JavaScript (프레임워크 없음)
- [Pyodide](https://pyodide.org) 0.27.7: 브라우저에서 Python(NumPy, openpyxl)을 실행합니다. 무거운 계산은 Web Worker에서 처리해 화면이 멈추지 않습니다.
- 글꼴: Pretendard (CDN)
- 배포: GitHub Pages (`.nojekyll`)

## 폴더 구조

```
index.html             화면 구성 (사이드바, 분석 패널, 오른쪽 패널)
style.css              디자인
app.js                 화면 동작 (분류 선택, 탐색, 시뮬레이션, 연쇄효과, CSV)
hero.js                파급 단계 예시
worker.js              Pyodide를 불러와 Python 계산을 실행하는 Web Worker
model.py               엑셀 읽기, 계수 검증, 시뮬레이션, 원자료 탐색
linkage.py             영향력계수와 감응도계수 계산
data/                  투입산출표 엑셀 파일 (분류별)
validation-report.json 계산 모듈 검증 기록
```

저장소 맨 위의 `io-2023.xlsx`는 `data/io-2023.xlsx`와 크기가 같은 사본입니다. 앱은 `data/` 안의 파일만 사용합니다.

## 내 컴퓨터에서 실행하기

엑셀 파일을 `fetch`로 불러오므로 `index.html`을 더블클릭해서는 동작하지 않습니다. 이 폴더에서 간단한 서버를 켜세요.

```
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. Pyodide와 글꼴을 인터넷에서 받아 오므로 인터넷 연결이 필요합니다.

## 알아 둘 점

- 시뮬레이션은 **양의 수요 증가**만 지원합니다. 수입 완제품 구매를 제외한 국내 생산물의 최종수요 증가를 입력합니다.
- 기본부문(12.3MB)은 첫 불러오기에 시간이 걸립니다. 처음에는 Pyodide도 함께 내려받습니다.
- 계수는 모두 2023년 투입산출표 기준이므로, 다른 연도의 구조 변화는 반영하지 않습니다.
